# Демо-экзамен. Вариант 1

**Вариант:** 1

## Описание проекта

WPF-приложение для расчёта баллов демо-экзамена. Пользователь выбирает уровень экзамена (БУ, ПУ, ПУ+), вводит баллы за модули, получает сумму баллов и оценку по 5-балльной шкале.
